# MatrixComplex
Практическая работа: матрицы комплексных чисел

## Функции:
- Сложение, вычитание, умножение, деление матриц комплексных чисел
- Транспонирование
- Определитель
- Обратная матрица
- Консольный интерфейс

## Структура:
- "src/Complex.java" - комплексное число
- "src/Matrix.java" - матрица комплексных чисел
- "src/Main.java" - консольный интерфейс
- ".gitignore" - исключения
- "README.md" - описание проекта

## Формат ввода:
- Размеры: два целых числа 
- Элементы: два числа через пробел (действительная и мнимая части)
- Дробная часть пишется через точку
- Матрицы A и B вводятся один раз и хранятся до выхода, поэтому можно выполнить несколько операций подряд

## Обработка ошибок

Программа не завершается аварийно: она выводит сообщение и возвращается в меню.

| Ситуация | Сообщение |
|---|---|
| Сложение и вычитание матриц разного размера | `Размеры матрицы должны совпадать!` |
| Умножение с несовместимыми размерами | `Для перемножения матриц число столбцов первой матрицы должно совпадать с числом строк второй!` |
| Определитель неквадратной матрицы | `Для нахождения определителя матрица должна быть квадратной!` |
| Обратная матрица вырожденной | `Матрица вырождена, обратной не может существовать!` |
| Деление на неквадратную матрицу | `Делить можно только на квадратную матрицу!` |
| Деление с несовместимыми размерами | `Для деления число столбцов первой матрицы должно совпадать с числом строк второй!` |
| Неверный пункт меню (не 1–10 и не 0) | `Неверный выбор! Попробуйте снова.` |
| Буквы вместо чисел | `Ошибка ввода: нужно вводить числа!` |
| Операция до ввода матриц | `Ошибка: сначала введите матрицы A и B!` |
